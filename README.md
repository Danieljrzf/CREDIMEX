# CREDIMEX

Sistema integral para la administración de una financiera de cobranza diaria.

## Componentes previstos

- Aplicación Android.

- API central.

- Base de datos PostgreSQL.

- Panel web administrativo en una versión futura.

## Estado actual

El proyecto se encuentra en la fase de diseño técnico.

Todavía no debe implementarse lógica financiera hasta aprobar:

1. Modelo conceptual de datos.

2. Diagrama entidad-relación.

3. Diccionario de datos.

4. Arquitectura técnica.

5. Contrato inicial de API.
